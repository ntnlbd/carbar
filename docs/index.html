AUM — month on month

Total value of available stock, at the latest check in each month.

How this is recorded: every day a scheduled GitHub Actions job re-scrapes carbarsale.ie and appends a snapshot (date, stock count, AUM, avg price) to a running history log committed back to the repo. This chart rolls those daily snapshots up to one bar per month — the AUM at each month's most recent check — so it grows one bar per month automatically.
